# 桌游规则卡片库 · 开局配件占用台

一个纯前端本地应用：在原有桌游规则遗忘点卡片库（容易忘的规则、常见争议、开局准备、计分提醒）之上，
扩展了聚会现场的"开局配件占用台"。

## 功能

- 预置三款游戏（奥尔良、盖亚计划、花砖物语）、三个桌位（按件数限定容量）和五种共用配件（全店共享库存）。
- 每局开局时选定游戏、桌位，并登记各种配件的数量：
  - 同种配件被其他**进行中局**占用后库存不足，或该桌位上的配件总件数超出桌位容量时，**整局拒绝**，已有占用保持不变。
  - 明知缺件可以"缺件登记"：局照常登记，但进入**冻结**状态，不占用任何配件和桌位；之后可"重启占用"，再按原登记数量重新校验，成功才转为进行中，失败则继续冻结。
  - 进行中的局也可以随时登记缺件冻结，占用立即释放。
- 进行中的局可以**结束**或**取消**，两种操作都会释放配件与桌位件数；记录留在历史局里，可一键清空。
- 在游戏详情里修改"开局配件方案"后，该游戏全部未结束局会**按新方案整组重算**；只要任一进行中局因此超限，整个修改退回，游戏方案与所有局都保持原样。
- 看板实时显示每个桌位的件数占用和每种共用配件的库存占用，超限标红。

## 结构（三层分开维护）

- `occupancy.js`：占用判断层。纯数据规则，不碰 DOM 也不碰存档；开局、重启、改方案等可能被拒的操作先产出"计划结果"，校验失败时不改动入参。
- `store.js`：存档同步层。预置数据、老版本卡片库存档迁移、localStorage 读写。
- `app.js`：页面事件层。表单、看板渲染和按钮操作，提交计划结果后再统一保存重绘。

## 使用

直接打开 `index.html` 即可，无需构建、无新增依赖、无额外页面。数据保存在浏览器 localStorage，
刷新页面后局状态、占用和游戏方案都会保留；清理浏览器站点数据会一并清除。
